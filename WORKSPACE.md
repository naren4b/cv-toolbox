# Workspace Guide

## Repository role

This repository is a public-safe, versioned toolbox. It contains reusable prompts, agents, generic skills, templates, and process documentation only.

## Google Drive role

Google Drive is the single private working workspace. It owns candidate data, leads, job folders, draft packages, review, submission confirmation, and the live status dashboard.

## Boundaries

- Do not commit personal information, job records, recruiter messages, or generated CVs to GitHub.
- Use repository assets as reusable instructions and templates.
- Use Google Drive for all case-specific work.
- Submission and permanent deletion require the user's explicit confirmation.
