# LinkedIn Lead Skill

## Purpose

Turn a LinkedIn opportunity, recruiter contact, or referral into a traceable lead in the Google Drive job-search workspace.

## Workflow

1. Capture the role title, company, source URL, and date found.
2. Record recruiter or referral context only in the Google Drive company folder.
3. Save the job description in `job.txt`.
4. Start the standard job-package workflow only when the user chooses to pursue the role.

## Rules

- LinkedIn is a discovery source, not the application system of record.
- Do not copy a candidate's profile, contact details, or private messages into this repository.
- Never send a connection request or message without the user's explicit instruction.
