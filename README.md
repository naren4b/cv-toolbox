# my-cv — Public Job Search Toolbox

This repository contains only reusable, generally shareable job-search workflow assets:

- Prompts and agents.
- Generic skills.
- Generic candidate-data templates.
- Process documentation and change history.

## Private working location

Google Drive is the sole location for personal profile information, leads, job descriptions, CVs, recruiter messages, application packages, and status tracking.

Do not add candidate-specific information or application records to this repository.
