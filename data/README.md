# Canonical Candidate Data

This folder is the only approved source for reusable candidate information. Keep one current copy of each record here.

| File | Purpose | Update when |
|---|---|---|
| `Master-CV.md` | Approved career history, skills, achievements, dates, and certifications | A fact changes or a major approved CV refresh is completed |
| `current-employer.txt` | Employer, title, start date, notice period, retention details, and reason for change | Employment or notice details change |
| `personal.txt` | Contact details, addresses, and other personal routing data | Contact or location details change |
| `salary.txt` | Current compensation and target compensation details | Compensation changes |

## Rules

- `Master-CV.md` wins when a career fact conflicts with another file.
- Never duplicate these details in prompts, agents, or job folders.
- Record approved major changes in `../CHANGELOG.md`.
- Copy a replaced major version to `../archive/YYYY-MM-DD/` before changing the canonical file.
