# Job Packages

Each folder represents one company and one application stream.

`STATUS.md` is the live application portfolio. Update it whenever a job folder changes stage.

## Required input

- `job.txt` — original job description.

## Optional input

- `email.txt` — recruiter or hiring-team message.

## Generated package

- `analysis.md` — role fit, requirements match, gaps, and CV choice.
- `cv-DD-MM-YYYY.md` — dated tailored CV.
- `prep.md` — interview preparation.
- `cover-letter.md` — role-specific cover letter.
- `company-info.md` — sourced company and compensation research.
- `email-reply.md` — created only when `email.txt` exists.
- `status.md` — deadline, stage, next action, and verified submission evidence.

Keep all files for a company in that company folder. Do not place personal or employer records here.

Use one of these stages in `status.md`: New, In preparation, Ready to apply, Submitted, Recruiter response, Interviewing, Offer, Closed, or Needs review.
